## *Descrição do Projeto*  
Este projeto foi desenvolvido como parte do portfólio da faculdade. O objetivo é criar uma *validação simples de campo de e-mail* usando *HTML* e *JavaScript*.

O sistema simula um formulário básico onde o usuário informa seu e-mail. O JavaScript verifica se o e-mail está no formato correto (ex: usuario@dominio.com) e exibe mensagens informando se está válido ou inválido, com uma orientação amigável e clara.

---

## *Como Funciona?*

A lógica do código verifica se o e-mail digitado:
- Possui caracteres antes e depois do @
- Contém um ponto . após o @
- Está preenchido corretamente

Se estiver *correto*, exibe a mensagem verde de sucesso.  
Se estiver *errado*, mostra uma mensagem vermelha explicando o formato correto.
